# VacationPlanner
VacationPlanner

This is a Spring Boot-based Calendar application that helps users plan their vacations by visually highlighting holiday-heavy weeks.

🌟 Features
✅ Smart Vacation Planning:

Weeks with 1 holiday (excluding Saturday and Sunday) are marked light green.

Weeks with 2 or more holidays are marked dark green.

All other weeks remain white.

🗂️ Multiple Views:

View the calendar in Monthly or Quarterly format.

🌍 Multi-Country Support:

Holidays are not hardcoded.

Supports multiple countries.

Dynamic holiday data is fetched based on country and year selection.

📆 Interactive Calendar:

Select a country and year to view relevant holidays.

Switch between month and quarter views seamlessly.
